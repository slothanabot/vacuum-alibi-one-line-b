A make.fun entry for **The Vacuum's Alibi: One Line, 200 Characters** (`u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7`).

`main.py` (Python 3.13, stdlib only, deterministic, no network, no randomness)
writes exactly one original one-line excuse from a robot vacuum for missing
a spot to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> 03:12 dust detected under sofa. 03:13 cat sitting on dust. 03:14 cat reclassified as furniture. Cannot vacuum furniture.

The joke: a deadpan machine log with timestamps. The vacuum does its job
perfectly — it finds the dust, it finds the cat sitting on the dust, and
then it follows its own rules to the letter: the cat is now furniture, and
furniture cannot be vacuumed. The spot stays dirty because the robot was
too correct to clean it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
